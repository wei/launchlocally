PRICING

There is no paid plan.

LaunchLocally is a hackathon project, built in one afternoon at the Agent Forge AI Hackathon Tokyo on 14 November 2026. We do not sell it and there is no hosted service to sign up for.

What is available

  • The code is public on GitHub: github.com/wei/launchlocally.
  • Recorded runs can be replayed in the browser on the recorded runs page. They are labelled as cached.

What running it yourself needs

LaunchLocally calls outside services during a run. You bring your own API keys, and each provider bills you under its own terms:

  • Tavily, for the research agents.
  • Daytona, for the sandbox that renders the video.
  • Nosana, for the GPU deployment that runs the voice model.
  • A model provider, for the language model that extracts facts, writes the script and plays the buyer. This build uses Nosana hosted inference when its catalog lists a chat model, and Ollama Cloud otherwise.

Setup steps are on the docs page.
